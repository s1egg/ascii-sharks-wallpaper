Before you install

  • If an older version is running, quit it from the fish icon in the menu bar first.
  • The app will be installed at /Applications/ASCII Sharks Wallpaper.app. The installer may ask for an administrator password.
  • Open ASCII Sharks Wallpaper from Applications, then use the fish icon to choose a scene, frame rate, swim speed, display coverage, or language.
  • This is an early local build with ad hoc app signing. Developer ID signing and Apple notarization are not configured, so other Macs may display a security prompt.
  • Quitting reveals your current system wallpaper. To uninstall, quit the app and move it from Applications to the Trash.
