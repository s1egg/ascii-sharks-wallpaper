# ASCII Sharks Wallpaper 0.1.2

2026 年 11 月 3 日本地发布版 · 构建号 3 · Apple Silicon · macOS 13 或更新版本

这一版让安静的海洋多了一点回应，也重新拉开了小鱼之间的距离。

## 本次更新

- **海洋会回应你。** 移动鼠标拨开附近鱼群，碰到小鱼才会产生涟漪；在经过的鲨鱼附近停留约 0.6 秒，它可能靠近查看，随后恢复巡游。可从菜单关闭“鼠标轻互动”。
- **逐渐认出它们的性格。** “混合物种”中的锤头鲨偏爱横向巡视，灰鲭鲨偶尔短促加速约三秒，长尾鲨则以更慢的摆尾舒缓转身。
- **偶然抬眼，有一点发现。** 现有的小鱼群偶尔穿过留白，或一条淡墨的少见物种从远处经过。1× 速度下，约一分钟后开始有机会出现，事件之间保留较长的安静时间；正在拨水或逗鱼时会适当延后。
- **画面重新疏朗。** 小鱼按最多七条的小群游动，间距更宽、墨色更淡；总量随画面面积控制在 24–64 条，偶遇不会增加小鱼总量。
- **保留原生桌面体验。** 点击继续穿透壁纸，键盘焦点留给其他应用；暂停、隐藏、减少动态效果和节能策略继续生效。

## 安装或升级

1. 从菜单栏鱼形图标中退出正在运行的旧版。
2. 解压 `ASCII-Sharks-Wallpaper-0.1.2-arm64.zip`，将应用移入“应用程序”；也可使用 `ASCII-Sharks-Wallpaper-0.1.2-arm64.pkg` 安装。
3. 打开 ASCII Sharks Wallpaper。已有的场景、语言、显示器、速度和播放偏好会保留；若此前没有保存过互动偏好，“鼠标轻互动”默认开启。

应用使用 ad hoc 签名，尚未配置 Developer ID 签名和 Apple 公证；在其他 Mac 上运行时，系统可能要求确认应用来源。安装器不会自动启动应用。本版仍不提供 Intel Mac 支持或自动更新。

## 本地发布包内容

发布目录包含 ZIP、PKG、各自的校验文件、`SHA256SUMS.txt`、中英文说明，以及记录准确源码 commit、构建号、工具链和验证结果的 `release.json`。

进入发布目录后，可检查全部文件：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

源码检查覆盖二十项模拟测试及原生 WebKit／菜单测试。多屏热插拔和真实睡眠、锁屏切换仍需在目标设备上验收。
